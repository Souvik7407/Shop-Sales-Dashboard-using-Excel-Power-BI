# 🛒 Shop Sales Dashboard | Excel + Power BI

## 📌 Project Overview
This project is a **Shop Sales Data Analysis Dashboard** created using **Microsoft Excel and Power BI**.  
The main objective of this project is to analyze sales performance and generate meaningful insights through interactive dashboards to support business decision-making.

The dataset was cleaned and prepared in **Excel**, then imported into **Power BI** for visualization and dashboard creation.

---

## 🎯 Objectives
- Analyze overall shop sales performance
- Track profit, quantity sold, and revenue trends
- Identify top-performing products and categories
- Understand customer purchase behavior
- Generate interactive reports for better decision-making

---

## 🛠 Tools & Technologies Used
- **Microsoft Excel** (Data Cleaning & Preprocessing)
- **Power BI Desktop** (Dashboard Development & Visualization)
- **DAX** (Measures and Calculations)

---

## 📂 Project Files
- `Souvik shop sales.xlsx` → Raw/Cleaned Dataset

## 📊 Dashboard Features
### ✅ Key KPIs Included

### ✅ Visualizations
- Monthly / Yearly Sales Trend (Line Chart)

- Top Selling Products
- Profit Analysis by Category

- Customer Purchase Behavior
- Interactive Filters & Slicers
